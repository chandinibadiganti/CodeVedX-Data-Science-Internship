# Sales Prediction Using Python

## 📌 Project Overview

This project focuses on predicting product sales based on advertising expenditure using Machine Learning.

The project analyzes the relationship between advertising platforms and sales and develops a model that can predict future sales based on advertising investments.

## 🎯 Objective

The main objective is to build a Machine Learning model that predicts sales using advertising expenditure on:

- TV
- Radio
- Newspaper

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Dataset

The dataset contains information about advertising expenditure and product sales.

The main features are:

- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales

## 🔧 Data Preprocessing

The following steps were performed:

1. Loaded the dataset.
2. Inspected the dataset.
3. Checked for missing values.
4. Checked for duplicate records.
5. Selected advertising expenditure as input features.
6. Selected Sales as the target variable.
7. Split the dataset into training and testing sets.

## 📊 Exploratory Data Analysis

The dataset was analyzed using visualizations to understand:

- Relationship between TV advertising and sales
- Relationship between Radio advertising and sales
- Relationship between Newspaper advertising and sales
- Correlation between advertising expenditure and sales

## 🤖 Machine Learning Model

A **Linear Regression** model was used to predict product sales based on advertising expenditure.

## 📈 Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

An Actual vs Predicted Sales graph was also created to evaluate the model visually.

## 🎯 Final Prediction

The trained model was used to predict sales for a new advertising budget based on TV, Radio, and Newspaper advertising expenditure.

## 💻 Platform

The project was developed and executed using **Google Colab**.
