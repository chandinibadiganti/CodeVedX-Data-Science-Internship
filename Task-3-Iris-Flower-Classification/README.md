# Iris Flower Classification

## 📌 Project Overview

This project focuses on classifying Iris flowers into different species using Machine Learning.

The Iris dataset contains measurements of flowers belonging to three species: Setosa, Versicolor, and Virginica. A classification model is trained to identify the species based on sepal and petal measurements.

## 🎯 Objective

The main objective is to develop a Machine Learning model that can accurately classify Iris flowers into their respective species.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Dataset

The Iris dataset contains the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The three target species are:

- Setosa
- Versicolor
- Virginica

## 🔧 Data Preprocessing

The following steps were performed:

1. Loaded the Iris dataset.
2. Inspected the dataset.
3. Checked for missing values.
4. Checked for duplicate records.
5. Selected the flower measurements as input features.
6. Selected species as the target variable.
7. Split the dataset into training and testing sets.

## 📊 Exploratory Data Analysis

The dataset was analyzed using visualizations to understand:

- Distribution of Iris species
- Petal length and petal width
- Relationships between flower measurements
- Differences between the three Iris species

## 🤖 Machine Learning Model

A **Logistic Regression** classification model was used to classify the Iris flowers into Setosa, Versicolor, and Virginica.

## 📈 Model Evaluation

The model was evaluated using:

- Accuracy Score
- Classification Report
- Confusion Matrix

## 🎯 Final Prediction

The trained model was used to predict the species of a new Iris flower based on its sepal and petal measurements.

## 💻 Platform

The project was developed and executed using **Google Colab**.
