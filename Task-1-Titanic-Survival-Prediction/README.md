# Titanic Survival Prediction

## 📌 Project Overview

This project focuses on predicting whether a passenger survived the Titanic disaster using Machine Learning.

The Titanic dataset contains information about passengers, such as passenger class, age, gender, fare, and other attributes. A classification model is trained to predict the survival status of passengers.

## 🎯 Objective

The main objective is to build a Machine Learning model that can classify passengers into:

- Survived
- Did Not Survive

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Dataset

The Titanic dataset contains passenger information including:

- Passenger Class
- Age
- Gender
- Fare
- Number of Siblings/Spouses
- Number of Parents/Children
- Embarked Port
- Survival Status

## 🔧 Data Preprocessing

The following steps were performed:

1. Loaded the Titanic dataset.
2. Inspected the dataset.
3. Checked for missing values.
4. Handled missing data.
5. Converted categorical values into numerical values.
6. Selected relevant features.
7. Split the data into training and testing sets.

## 📊 Exploratory Data Analysis

The dataset was analyzed using visualizations to understand:

- Overall survival distribution
- Survival based on gender
- Survival based on passenger class

## 🤖 Machine Learning Model

A **Logistic Regression** classification model was used to predict passenger survival.

The model was trained using the training dataset and then tested using unseen test data.

## 📈 Model Evaluation

The model was evaluated using:

- Accuracy
- Classification Report
- Confusion Matrix

## 🎯 Final Prediction

The trained model was used to predict whether a sample passenger was likely to survive or not.

## 💻 Platform

The project was developed and executed using **Google Colab**.
