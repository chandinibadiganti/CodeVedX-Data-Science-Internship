# Movie Rating Prediction

## 📌 Project Overview

This project focuses on predicting the rating of a movie using Machine Learning and historical movie data.

The project analyzes movie-related features and builds a regression model to estimate the rating of a movie.

## 🎯 Objective

The main objective is to develop a Machine Learning model that can predict movie ratings based on available movie information.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📂 Dataset

The dataset contains information about movies, including features such as:

- Movie Name
- Genre
- Director
- Actors
- Year
- Duration
- Votes
- Rating

## 🔧 Data Preprocessing

The following steps were performed:

1. Loaded the movie dataset.
2. Inspected the dataset.
3. Checked for missing values.
4. Removed or handled missing data.
5. Converted relevant data into numerical form.
6. Selected suitable features for prediction.
7. Split the dataset into training and testing sets.

## 📊 Exploratory Data Analysis

The movie dataset was analyzed using visualizations to understand:

- Distribution of movie ratings
- Relationship between votes and ratings
- Movie rating patterns
- Important factors related to movie ratings

## 🤖 Machine Learning Model

A **Linear Regression** model was used to predict movie ratings.

The model was trained using historical movie data and then used to estimate ratings for unseen data.

## 📈 Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

These metrics were used to measure the performance of the prediction model.

## 🎯 Final Prediction

The trained model was used to predict the rating of a sample movie based on its available features.

## 💻 Platform

The project was developed and executed using **Google Colab**.
